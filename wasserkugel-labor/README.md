# Wasserkugel-Labor (WebGPU)

3D-Flüssigkeits- und Planeten-Labor im Browser (WebGPU).

- `euler.html` – Gitter-Strömung (Stam Stable Fluids, Vorwirbel, Marker): Tasse mit Milch/Tee, Wasserkugel
- `index.html` – MLS-MPM-Teilchen: Planeten, Mond-/Asteroideneinschlag, 6 Darstellungsverfahren (V1–V6)
- `dist/` – veröffentlichte Fassung (wasserkugel.html, planet.html)
- `test/` – Zeitraster-Tests (Playwright + lavapipe), Farbmessung gegen Referenzfotos
- `ref/` – Referenzfotos
- `PLAN.md` – was funktioniert hat, was nicht, wie es weitergeht

Starten: Datei im WebGPU-fähigen Browser öffnen (Chrome/Edge aktuell).
